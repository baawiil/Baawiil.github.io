# Baawiil V4

Portfolio gaming Tailwind CSS v4, avec accueil interactif, certifications, contacts et SEO.

## Publier

Importer le contenu à la racine du dépôt puis vérifier Settings > Pages > GitHub Actions.
Le workflow copie également `robots.txt` et `sitemap.xml`.

## Contact

GitHub est le seul lien social public connu. Ajouter Discord/autres réseaux uniquement après choix de leurs URLs.

## Partages

Open Graph et Twitter Card sont renseignés sans image dédiée. Une image `og:image` pourra être ajoutée ultérieurement.

## Formations

« Monteur vidéo LPA » est notée obtenue et « Formation Retouche Photo (Photoshop) » est notée en cours, selon les informations fournies.
