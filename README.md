# Portfolio Baawiil V5

Version sans les anciennes cartes de projets. Conserve le design gaming, les compétences interactives, la section Certifications & formations LPA, les contacts et les balises SEO.

## Déploiement

Téléverser `index.html` et `script.js` à la racine du dépôt GitHub Pages, en remplaçant les fichiers existants. Le workflow GitHub Actions actuel compile automatiquement Tailwind. Les autres fichiers du dépôt sont inchangés.
